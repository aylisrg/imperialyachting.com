# Правила live-сайта Imperial Yachting

## Структура
- `content/fleet.json` — флот. `content/clips.json` — клипы (пишется скриптом, руками только role/порядок).
- `clips/<name>-1920|960.mp4|webm` + `clips/<name>.jpg` — видео и постер.
- Страница сама строит флот и подставляет видео из JSON. Открывать через http-сервер (не file://).

## Добавить яхту
1. Сделать клип: `scripts/make-clip.sh <youtube-id> <start> <dur> <slug>-<что> fleet`.
2. Добавить объект в `content/fleet.json`: `slug, name, hull, builder, loa, guests, built, refit, berth, clips:[...]`.
3. Только проверенные данные (документы, сайт). Неизвестно: `null`, поле не покажется. Никаких цен, «лучших», рейтингов.

## Добавить видео/клип
- `scripts/make-clip.sh <id> <start_s> <dur_s> <name> [hero|section|fleet|people] [crop w:h:x:y] [poster_offset]`
- Скрипт качает исходник в `../video/src/<id>.mp4` (если YouTube блокирует скачивание, положить файл туда вручную), режет, делает бесшовную петлю (0,5 с перекрестное затухание), кодирует H.264 Main yuv420p faststart без звука + WebM VP9, 1920 и 960, постер, обновляет clips.json.
- Hero один: role `hero`. Сменить hero = поменять role у двух клипов.
- В продакшене клипы лежат на Vercel/CDN, не YouTube iframe.

## Правила кадра
- Длина 4-8 с, один план, без склеек внутри. Проверять раскадровкой (`ffmpeg ... select='gt(scene,0.25)'`).
- Никаких надписей, таймеров, логотипов, «Subscribe», плашек с именами, сплит-скрина (иначе crop).
- Свет: утро, золотой час, ясный день. Без пересвета и ночного шума.
- Движение: яхта идет, дрон, кильватер. Статичные интерьеры только в section.
- Люди: лица только с согласия, без случайных гостей крупно. Ильи и Миши: только подтвержденные ими кадры.
- Безопасная зона: главный объект в центральной трети по горизонтали (мобильный кроп 9:19 режет края). Вертикальные шортсы годятся только для мобильной версии.

## Размеры и имена
- 1920: до 5 МБ на клип, 960 (мобильный): до 2 МБ на клип, включая hero. Постер JPG до 300 КБ.
- Без тапа автозагружается только hero. Остальные клипы грузятся только когда секция входит в экран.
- Если 960 больше 2 МБ: пережать (VP9 CRF 42, H.264 CRF 28) или укоротить.
- Имена: латиница, дефисы: `<яхта или тема>-<действие>`, например `vd40-aerial`, `moneta-golden`.
- Не больше 6 клипов на страницу, видео грузится только у своей секции.

## Люди в кадре (тег people)
- Клип, где в кадре кто-то из команды, режем с ролью `people`, потом добавляем в `content/clips.json` поле `"people": ["ilia"]` (ключи: `ilia`, `misha`, латиницей, строчными).
- Ставим только тех, кого подтвердил Илья. Гостей и клиентов не тегаем и в блок команды не ставим.
- Людей не ставим в hero. Их место: блок `crew` ("On board. Every time.") после Owned/Operated.
- В подписи только имя и место (без должностей и цифр, которых нет в фактах).
- Клип с человеком: одна сцена без склеек, лицо видно на протяжении всей петли, 4–6 с.
