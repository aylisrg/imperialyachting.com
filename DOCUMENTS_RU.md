# Раздел «Документы» под паролем

Страница `/documents` теперь закрыта паролем. Вы отправляете партнёру/клиенту
ссылку `https://imperialyachting.com/documents`, он открывает её, вводит пароль —
и получает доступ к красивому разделу, где можно скачать все документы (License,
EJARI и др.) и посмотреть полную информацию о компании и банковские реквизиты.

---

## 1. Как задать пароль

Пароль один общий — вы сообщаете его тем, кому даёте доступ.

Задайте переменную окружения (в Vercel: **Project → Settings → Environment
Variables**):

```
DOCUMENTS_PASSWORD = ваш_надёжный_пароль
```

После добавления переменной сделайте **Redeploy** проекта.

> Если переменная не задана, временно действует запасной пароль
> `ImperialDocs2025`. **Обязательно** задайте свой `DOCUMENTS_PASSWORD` для
> продакшена.

Чтобы сменить пароль — измените переменную и сделайте redeploy. Все старые сессии
(у тех, кто уже вводил пароль) при этом автоматически сбрасываются.

Опционально можно задать отдельный секрет для подписи cookie:

```
DOCUMENTS_SESSION_SECRET = любая_длинная_случайная_строка
```

Это не обязательно — если не задать, подпись формируется на основе пароля.

## 2. Как добавить сами PDF-файлы

Файлы лежат **не** в `/public` (чтобы их нельзя было открыть по прямой ссылке без
пароля), а в папке `private/documents/`. Сайт отдаёт их только после ввода пароля.

Положите PDF в `private/documents/` с такими именами:

| Документ                     | Имя файла                            |
| ---------------------------- | ------------------------------------ |
| Trade License                | `trade-license.pdf`                  |
| EJARI Tenancy Contract       | `ejari.pdf`                          |
| Certificate of Incorporation | `certificate-of-incorporation.pdf`   |
| Establishment Card           | `establishment-card.pdf`             |
| Memorandum of Association    | `memorandum-of-association.pdf`      |

Как только файл появляется в папке, на странице у соответствующего документа
загорается кнопка **Download**. Пока файла нет — показывается надпись
«Available on request», и страница при этом не ломается.

Закоммитьте файлы в репозиторий (`git add private/documents/*.pdf`) и
задеплойте — этого достаточно.

### Изменить список / названия документов

Всё описание документов (заголовки, тексты, категории, имена файлов) — в одном
файле: `src/lib/documents.ts`. Там можно добавить новые документы, удалить
лишние или переименовать.

## 3. Как это устроено (кратко)

- **`/documents`** — серверная страница. Нет cookie → показывает экран ввода
  пароля. Есть валидный cookie → показывает полный раздел с документами.
- **`POST /api/documents/unlock`** — проверяет пароль, ставит подписанный
  httpOnly-cookie на 7 дней.
- **`GET /api/documents/file/[slug]`** — отдаёт PDF, но только при наличии
  валидного cookie. Без пароля файл скачать нельзя даже по прямой ссылке.
- Страница помечена `noindex` и закрыта в `robots.txt` — поисковики её не
  индексируют.

Кнопка **Lock** в правом верхнем углу (и внизу страницы) сбрасывает доступ —
удобно, если открывали на чужом устройстве.
