# Раздел «Yachts for Sale» — продажа яхт

`/yachts-for-sale` — раздел продажи яхт для брокеров и покупателей.
**В меню и футере сайта ссылки нет**, но раздел открыт для поисковиков и
AI-ассистентов: он есть в `sitemap.xml`, `llms.txt`/`llms-full.txt`, на
публичном MCP (`list_yachts_for_sale`), размечен JSON-LD и при каждом изменении
отправляется в IndexNow.

Сейчас на продаже:

| Яхта | URL | Откуда данные |
|---|---|---|
| VanDutch 40 «Van Dutch Connect» | `/yachts-for-sale/vandutch-40-van-dutch-connect` | Тех. спецификация (PDF) + фото/видео яхты `vd-40` из флота |
| Monte Carlo 6 «Moneta» | `/yachts-for-sale/monte-carlo-6-moneta` | Год, размеры, каюты, спеки, фото и видео — из яхты `monte-carlo-6` во флоте |

## Как брокеры работали раньше — и что изменили

| Было | Стало |
|---|---|
| PDF-брошюры по почте и в WhatsApp, которые устаревают через неделю | Одна ссылка на яхту. Статус (Available / Under offer / Sold), цена и дата обновления — всегда актуальные |
| «Пришлите брошюру» → ждать ответа, WeTransfer-ссылки протухают | Галочками выбрал материалы → email один раз → файлы скачиваются сразу. Email запоминается — в следующий раз один клик |
| Споры «чей клиент», кто первым прислал | Брокер ставит «I'm a broker» и вписывает клиента прямо в форме скачивания. Запись с таймстемпом в БД + подтверждение ему на почту |
| Условия ко-брокериджа выясняются перепиской | Условия написаны прямо под кнопкой скачивания (`broker_terms`, меняется через MCP) |
| Страницы перегружены маркетингом | Страница яхты = лист-листинг: ключевые цифры, короткий обзор, спецификация (свёрнута по секциям), пакет материалов справа. SEO-тексты вынесены на хаб |
| Непонятно, кто смотрел материалы | Письмо + Telegram на каждое скачивание: кто, брокер или покупатель, компания, клиент, что взял, страна, сколько раз уже скачивал |

## Что происходит при скачивании

1. Посетитель отмечает материалы (по умолчанию отмечено всё) → «Download N files».
2. Вводит email (+ опционально «I'm a broker», компания, клиент) → «Download now».
3. Сервер (`POST /api/sales/download`):
   - записывает строку в `sale_download_requests`;
   - шлёт **вам** письмо (reply-to = email брокера, можно сразу ответить) и Telegram;
   - шлёт **брокеру** копию ссылок (действуют 7 дней) и подтверждение регистрации клиента;
   - возвращает подписанные ссылки — браузер сразу начинает загрузку.
4. PDF и приватные файлы никогда не доступны по прямой ссылке — только по
   подписанной ссылке с истекающим сроком.

«Photo pack» и «Video pack» собираются автоматически из всех фото/видео
листинга (свои + из флота), без водяных знаков, файлы именуются
`<slug>-photo-01.jpg` и т. д.

## Запуск (один раз)

1. **Применить миграцию** `supabase/migrations/008_yacht_sales.sql` в Supabase
   (Dashboard → SQL Editor). Она создаёт таблицы, бакеты `sale-media`
   (публичный) и `sale-materials` (приватный) и заводит обе яхты. Без неё
   раздел просто показывает «листинги готовятся» — сайт не падает.
2. **Переменные окружения в Vercel:**
   - `SALES_ADMIN_TOKEN` — ваш секретный токен для MCP (`openssl rand -hex 32`);
   - `SALES_NOTIFY_EMAIL` — куда слать уведомления о скачиваниях (например, ваш Gmail);
   - `RESEND_API_KEY` (+ `BOOKING_FROM_EMAIL`) — уже используется для броней; без него письма не уходят, Telegram работает;
   - `SALES_FILE_SECRET` — необязательно (иначе ключ выводится из `SUPABASE_SERVICE_ROLE_KEY`).
3. После деплоя: отправить `https://imperialyachting.com/sitemap.xml` в Google
   Search Console и Bing Webmaster (IndexNow уже пингуется автоматически).

## Управление через MCP (доступ только у вас)

Приватный MCP: `https://imperialyachting.com/api/mcp/sales` — без токена
отвечает 401.

- **Claude Code:**
  `claude mcp add --transport http imperial-sales https://imperialyachting.com/api/mcp/sales --header "Authorization: Bearer <SALES_ADMIN_TOKEN>"`
- **claude.ai / ChatGPT (custom connector, только URL):**
  `https://imperialyachting.com/api/mcp/sales?key=<SALES_ADMIN_TOKEN>`
  (URL с токеном = пароль, никому не пересылайте).

| Инструмент | Что делает |
|---|---|
| `sales_list_listings` | Все листинги, включая черновики, со счётчиком скачиваний |
| `sales_get_listing` | Полная карточка + медиа + материалы (с id для удаления) |
| `sales_upsert_listing` | Создать/обновить: текст, спеки, цена, статус (`draft`/`published`/`under_offer`/`sold`), `fleet_yacht_slug`, условия для брокеров |
| `sales_add_media` | Фото/видео/YouTube на страницу. Из ссылки (Google Drive/Dropbox, ≤50 МБ), base64 (≤15 МБ) или после прямой загрузки |
| `sales_add_material` | Материал в пакет скачивания: PDF, брошюра, сюрвей, видео. Файлом (в приватный бакет) или внешней ссылкой (`link_url`, например папка с 4K) |
| `sales_create_upload_url` | Ссылка для прямой загрузки больших файлов (видео) + готовая команда `curl` |
| `sales_remove_item` | Удалить фото/материал вместе с файлом |
| `sales_list_downloads` | Кто что скачал (фильтр по яхте, только брокеры) |

Примеры запросов ассистенту:

- «Поставь VanDutch в статус under offer»
- «Добавь брошюру Monte Carlo из этой ссылки Google Drive в материалы»
- «Цена VanDutch — 850 000 AED»
- «Кто из брокеров скачивал материалы по Moneta за неделю?»
- «Сделай новый листинг для EVO 43, черновиком, возьми всё из флота (evo4)»

Любое изменение сразу обновляет страницу, sitemap и llms.txt и пингует IndexNow.

## SEO / GEO

- Хаб `/yachts-for-sale`: «Yachts for Sale in Dubai», блок для брокеров,
  гайд по покупке яхты в Дубае (свёрнутые секции — индексируются), FAQ;
  JSON-LD `CollectionPage` + `FAQPage` + `BreadcrumbList`.
- Страница яхты: свой `title`/`description`/ключевые слова, canonical, OG,
  JSON-LD `Product` (б/у, бренд, модель, год, все спеки как
  `additionalProperty`; `Offer` появляется, когда указана цена), `FAQPage`,
  `VideoObject`.
- `llms.txt` / `llms-full.txt` — раздел «Yachts for Sale» с полными спеками.
- Публичный MCP — `list_yachts_for_sale` для ChatGPT/Claude/Perplexity.
- Раздел без ссылок из меню = «сиротские» страницы: их находят через
  sitemap/IndexNow, но вес у них ниже. Чтобы ускорить индексацию, дайте на
  листинги несколько внешних ссылок (Instagram bio/сторис, LinkedIn, профили
  на площадках вроде YachtWorld/Boat24).
