# IndexNow

## Что это

[IndexNow](https://www.indexnow.org/) — открытый протокол, по которому сайт
может мгновенно уведомлять поисковые системы (Bing, Yandex и другие
участники протокола) об изменении или появлении страницы, не дожидаясь
планового обхода краулером. Google в самом протоколе не участвует, но для
Bing и Яндекса это заметно ускоряет переиндексацию.

В этом проекте IndexNow подключён так:

- `src/lib/seo/indexnow.ts` — функция `submitToIndexNow(urls)`, которая
  отправляет POST-запрос на `https://api.indexnow.org/indexnow` с ключом,
  списком URL и адресом файла-подтверждения ключа. Если переменная
  окружения `INDEXNOW_KEY` не задана, функция ничего не отправляет и
  возвращает `{ ok: false, skipped: true }`.
- `src/app/api/indexnow/key/[key]/route.ts` вместе с `rewrites()` в
  `next.config.ts` отдаёт файл подтверждения ключа по адресу
  `https://imperialyachting.com/{key}.txt`, как того требует протокол.
- `src/app/api/indexnow/submit/route.ts` — защищённый эндпоинт (нужен
  залогиненный Supabase-пользователь), которым админка дёргает отправку
  после сохранения записи.
- Админка (`src/app/admin/yachts/[id]/page.tsx` и
  `src/app/admin/destinations/[id]/page.tsx`) после успешного сохранения
  яхты/направления в фоне (fire-and-forget, без блокировки и без падения
  сохранения при ошибке) вызывает `/api/indexnow/submit` со ссылками на
  изменённую страницу и на список.

## Как сгенерировать ключ

Ключ IndexNow — это произвольная строка из 32 hex-символов (0-9, a-f).
Сгенерировать можно любым способом, например:

```bash
openssl rand -hex 16
```

Получится что-то вроде `8f1a2c3d4e5f60718293a4b5c6d7e8f9`.

## Настройка в Vercel

1. Открыть проект в Vercel → Settings → Environment Variables.
2. Добавить переменную `INDEXNOW_KEY` со значением сгенерированного ключа
   для окружения Production (и, при необходимости, Preview).
3. Сделать redeploy, чтобы переменная подхватилась.

## Проверка файла подтверждения ключа

После деплоя ключ должен быть доступен по адресу
`https://imperialyachting.com/{key}.txt` (замените `{key}` на реальное
значение `INDEXNOW_KEY`) и отдавать `200 OK` с телом, равным самому ключу,
`Content-Type: text/plain`. Проверить можно так:

```bash
curl -i https://imperialyachting.com/<ваш-ключ>.txt
```

Если ключ не задан в переменных окружения или в запросе передан не тот
ключ — маршрут вернёт `404`.

## Регистрация в Bing Webmaster Tools

1. Зайти в [Bing Webmaster Tools](https://www.bing.com/webmasters) и
   добавить/выбрать сайт `imperialyachting.com`.
2. В разделе **IndexNow** (Settings → IndexNow либо соответствующий пункт
   меню) указать URL с ключом подтверждения, например:
   `https://imperialyachting.com/<ваш-ключ>.txt`.
3. Bing проверит файл по этому адресу и, если содержимое совпадает с
   ключом, подтвердит владение — после этого сайт начнёт получать
   моментальные обновления через IndexNow API автоматически, без
   дополнительной настройки на стороне Bing.

Отдельная регистрация в Яндекс.Вебмастере не требуется — Яндекс участвует
в общем протоколе IndexNow и получает уведомления так же, через
`api.indexnow.org`.
